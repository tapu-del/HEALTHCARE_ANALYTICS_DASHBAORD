# Healthcare Analytics Dashboard

## Project Overview
Built a clean, professional Power BI dashboard to analyze 55,000+ hospital patient records using a Teal & White medical theme.

## Tools Used
- Power BI
- Excel

## What I Did
- Analyzed total patients, total billing amount, and average age.
- Created a bar chart to show the highest billing medical conditions.
- Built a donut chart to show the gender distribution.
- Created a column chart for admission types (Elective, Urgent, Emergency).
- Added a slicer for medical conditions.

## Key Insights
- **Total Patients:** 55.5K
- **Total Billing:** 1.42 Billion
- **Top Conditions:** Diabetes and Obesity generate the highest billing amounts.
- **Admissions:** Elective and Urgent admissions are almost evenly split.
